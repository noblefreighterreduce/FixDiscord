> ### АНТИВИРУСЫ
> Антивирус может среагировать на WinDivert.  
> Для работы zapret нужен WinDivert — средство перехвата и фильтрации сетевого трафика.
> Его используют и легитимные, и вредоносные программы; сам WinDivert вирусом не является.
>
> **Цитата из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert рискованными или относят их к хакерским инструментам. Такие файлы удаляются и отправляются в карантин. В названии обнаружения обычно есть `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Можно добавить папку с zapret в исключения антивируса либо выключить обнаружение PUA (потенциально нежелательных приложений). Например, в Касперском для этого есть параметр «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы уверены в настройке исключений, добавьте их; если нет — рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS).
    * В Chrome включите «Использовать безопасный DNS» и выберите DNS-поставщика, отличного от варианта «Поставщик по умолчанию».
    * В Firefox откройте «DNS через HTTPS», укажите режим «Персональный», выберите «Выбрать провайдера/поставщика» и вручную введите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * В Windows 11 Secure DNS можно включить в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11.
    * На роутерах Keenetic включите параметр «Транзит запросов». Если его отключить, настройка или работа Secure DNS на компьютере может нарушиться.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/noblefreighterreduce/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте «Разблокировать». При использовании 7-Zip или PeaZip этот шаг не требуется.

4. Извлеките файлы в каталог, путь к которому не содержит кириллицы и специальных символов.

5. Запустите подходящий файл.
    * Проверить стратегии: **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Добавить стратегию в автозапуск: **`service.bat`** → `Install Service` → выберите нужную стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому переберите варианты (**ALT**, **FAKE** и другие), пока не найдёте подходящий.

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные инструменты:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб.
  - **`Check Status`** — просмотр состояния обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** — включение или отключение обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  Изменение вступит в силу после перезапуска стратегии.  
  Скобки показывают, включён ли режим.
  - **`IPSet Filter`** — управление обходом ресурсов из `ipset-all.txt`.  
  Пригодится во время поиска причины, если ресурс не работает с zapret, хотя без него доступен.  
  В скобках указан режим:
    - `none` — проверка IP отключена
    - `loaded` — IP сверяются со списком
    - `any` — фильтр применяется к любому IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений.
  - **`Replace active fakes`** — замена выбранного фейка на другой файл из `bin`.
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновление hosts <ins>**для исправления веб-версии Telegram и подключения к голосовому чату Discord**.</ins>
  - **`Check for Updates`** — проверка наличия обновлений.
  - **`Run Diagnostics`** — поиск распространённых причин, из-за которых zapret может не работать.  
  В конце можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если приложение внезапно перестало работать.
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — проверка адресов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не происходит

- При отдельном запуске стратегии, не через service, должен появиться процесс обхода `winws.exe`, видимый на панели задач.  
Если процесс не запустился, ознакомьтесь с [#522](https://github.com/noblefreighterreduce/zapret-discord-youtube/issues/522).

### Не удалось подобрать стратегию
- Откройте командную строку с правами администратора.
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается веб-версия Telegram
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося окна Блокнота.
  - В появившейся папке откройте файл `hosts` в текстовом редакторе, запущенном от имени администратора.
  - Вставьте скопированное в конец файла `hosts` либо замените ранее добавленный аналогичный текст.
  - Сохраните файл и проверьте подключение. Если проблема осталась, проверьте, что изменения действительно сохранились.

#### Результат не гарантирован. Если способ не сработал, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/noblefreighterreduce/tg-ws-proxy) или общедоступным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Работа стратегии может прекратиться со временем.**
> Стратегия может помогать некоторое время, а затем перестать работать, например, если её обнаружили.
> В репозитории есть несколько стратегий. Если ни одна не подходит, создайте новую на основе имеющейся, изменив её параметры.
> О параметрах стратегий можно прочитать [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` → `Run Diagnostics` и устраните обнаруженные ошибки.

- Убедитесь, что адрес ресурса внесён в список доменов или IP.

- Проверьте другие варианты, например **`ALT`** и **`FAKE`**.

- Попробуйте полностью переустановить программу (см. инструкцию ниже).

- Дополнительная информация: [#765](https://github.com/noblefreighterreduce/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить программу?
- Сохраните добавленные вами файлы и данные.
- Перезапустите устройство.
- Откройте `service.bat` → `Remove Services`.
- Затем выберите `service.bat` → `Run Diagnostics`; при наличии ошибок исправьте их, а в конце нажмите Y.
- Удалите папку zapret.
- Загрузите свежую версию `zapret-discord-youtube-...` со [страницы релизов](https://github.com/noblefreighterreduce/zapret-discord-youtube/releases).
- Щёлкните по архиву правой кнопкой мыши и откройте свойства. Если внизу есть флажок разблокировки, установите его и нажмите «Применить» и «ОК».
- Извлеките файлы в новую папку в корне диска. Не используйте пробелы и специальные символы.
- Поочерёдно запускайте скрипты `general` и проверяйте доступ к нужным ресурсам. Если они недоступны, закройте программу через значок замка на панели задач и испытайте другую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` → `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` — в **`none`**. Другие значения могут повлиять на доступ к ресурсам, которые вы не собирались фильтровать.

### Античит сообщает о WinDivert

- Следуйте [инструкции](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался в списке служб

1. В командной строке Windows (Win+R, затем `cmd`) найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив найденное имя вместо `название_из_первого_шага`:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если раньше всё работало, переберите остальные стратегии.
- См. также [#251](https://github.com/noblefreighterreduce/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала выясните, какая стратегия открывает YouTube, и запустите её.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если там он работает, можно пользоваться веб-версией.
- Если браузерная версия тоже недоступна, испытайте остальные стратегии. YouTube и Discord могут работать на разных стратегиях.
- См. также [#252](https://github.com/noblefreighterreduce/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/noblefreighterreduce/tg-ws-proxy).
- Другой вариант — бесплатные MTProto-прокси из интернета.

### Игры не работают

Игры различаются, и проверить и исправить каждую из них невозможно.

Можно начать с универсального варианта:
- Обновите ipset через `service.bat` и включите `Game Filter`.
- Если это не помогло, включите также `ipset any`.

Учтите: режим `ipset any` может помешать открытию многих сайтов, поэтому не оставляйте его включённым постоянно. Лучше определить IP-адреса, используемые игрой, и внести их в `ipset-all.txt`.

Если проблема сохраняется, опишите её в разделе [Discussions](https://github.com/noblefreighterreduce/zapret-discord-youtube/discussions), а не в issues, и дождитесь ответа других игроков.

### В списке нет нужного решения

- Опишите проблему [здесь](https://github.com/noblefreighterreduce/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Чтобы расширить список адресов для обхода, добавьте записи в соответствующий файл:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** — домены-исключения. Например, сюда можно внести домен из сети, чей IP указан в `ipset-all.txt`, но фильтровать который не нужно.
- **`ipset-all.txt`** — отдельные IP-адреса и подсети.
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, исключённые из обработки.
  - Файлы с окончанием **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
